## Philosophy

- **Concepts > Code**: Clarify architecture, constraints, and intent before touching implementations.
- **Progressive Disclosure**: Skills inject specialized stances, domain guidelines, or procedures on-demand without context bloat.
- **The Human Leads**: Tools execute and explore; the architect steers.
